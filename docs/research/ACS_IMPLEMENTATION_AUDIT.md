## 对论文差异判断的修正

作者材料包含球面预采样、方向聚类和自适应抽样。论文作者博士论文第 3 章 Algorithm 3 给出了分簇局部分布和全局混合，第 3.3.2 节另讨论增量重要性权重。应区分构造分布的分量系数与估计失效概率的权重。代码中使用目标密度构造分量系数，与 Algorithm 3 的相应表达有对应关系。[作者报告](https://ispd.cc/slides/2019/25_PD_Adaptive.pdf) · [第一作者博士论文，第 3 章，印刷页 31–38](https://escholarship.org/content/qt58f61961/qt58f61961_noSplash_5af6b5baafcfcae77097c91fc3fa01ea.pdf#page=45)

下面独立推导一种条件下的化简。每个失效点记为 `x_i`，在它附近的一个高斯分布记为 `q_i(x)`。设每个点的正系数是 `beta_i`，一组点的系数之和是 `B_j`，所有点的系数之和是 `B`。

一组点先混成一个局部分布。

\[
g_j(x)=\sum_{i\in C_j}\frac{\beta_i}{B_j}q_i(x)
\]

如果全局再按每组的系数总和进行混合，就有

\[
g(x)=\sum_j\frac{B_j}{B}g_j(x)
=\sum_i\frac{\beta_i}{B}q_i(x).
\]

这里分组的总系数约掉了。所以，只要点集合、核参数和混合规则满足这些条件，把点先分组再混合，与一次性混合全部点有相同密度。若分组还改变核参数、截断范围、局部样本更新或抽样配额，就需要重新分析。该推导无法证明整个 ACS 流程等价。

## 下一项最小研究

先核对初始化与参数坐标的定义。历史实现的均匀盒与作者的球面预采样有明确区别。球面半径应在哪种参数坐标中定义、怎样从名义点和工艺尺度映射、每层怎样计费，需要先写清楚。真实保持裕量案例的低权重仍然是待解释的结果，静态密度化简没有解释这一结果。

对照分两步。第一步固定同一候选集合，比较构造出的分布和每批估计的独立计算，已完成的是其中的静态密度检查。第二步只改变一个已定义清楚的初始化步骤，历史行为作为 A，研究修正作为 B，保留各自配置和历史身份。两组使用同一目标分布、失效事件、每任务预算、正式批次和预登记种子；初始化、复测与正式估算均计费。候选不足、无估计和差结果均保留。

最先使用具有可计算真值的双失效区域解析问题，测量函数替代电路，同时复用生产提议和估计路径。核对每批生成分布、实际分母、样本重用与停止规则后，再制定 SRAM 对照资源方案。多轮数值一致本身不能推出一般无偏性或有效置信区间。

当前尚未确定完整球面初始化的实现细节，也未确认累计失效池与论文逐轮更新的等价性。恢复聚类注释、替换分量权重或扩大仿真预算，都需要各自的依据。算法生产代码在本轮保持现有实现。
