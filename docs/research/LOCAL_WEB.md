# 本地良率测评页面

在已安装 OpenYield 环境的 WSL 或 Linux 中，从仓库根目录启动。

```bash
conda activate openyield
python -m yield_estimation.evaluation.web
```

打开 `http://127.0.0.1:8765`。页面使用 Python 标准库。端口被占用时可加 `--port 8766`，输出默认在 `outputs/local_yield/`。

## 配置和校验

表单支持电路类型、六种操作、阵列、目标单元、工艺角、电压、温度、抽样方式、完整/等效阵列、门限、算法和预算。SNM 固定单单元。四种 IS 只接受 `custom` 和完整阵列。各项生效位置见[配置清单](CONFIGURATION_MAP.md)。

初始 JSON 来自公开案例，保留四种 IS 明显低估的设置，用于演示。修改表单后点击“将表单写入 JSON”，再点击“校验配置”。实际提交以 JSON 为准，解析后的配置可展开查看。初始化、选点、提议分布、6T 尺寸与互连可编辑 JSON。表单每个算法一个选择项；多个同算法策略可在 JSON 中使用不同 ID，并直接校验 JSON。

校验调用 `normalize_experiment`，只表示程序接受设置。电路能否运行、门限依据和预算充分性需要各自实验。10T 和其他组合有接入路径，本轮完整真实流程证据限于公开的 1×1 6T 保持裕量案例。

仅填外层或仅填 `circuit.corner` 时，后端记录统一值。两处冲突时，网页、命令行与 Python 入口都拒绝。

## 运行与独立参考

校验后显示任务数量和预算上限。“运行已校验配置”调用现有 `experiment` 模块并启动 Xyce。独立参考每行填一个包含 `run_summary.json` 的目录，入口固定其摘要哈希，分析时检查工况与独立性。

本地服务串行处理任务。整轮限时默认 600 秒，可填 1–3600 秒。超时先终止包括 Xyce 的进程组，10 秒后仍未结束则强制终止。失败和超时后按已有冻结清单分析，缺少摘要的条目仍保留。

HSCS 读测评需显式启用历史辅助写策略。辅助写发生在末行末列，并沿用读门限数值指导搜索，费用计入预算。正式估计用读样本，其搜索策略合理性需要单独研究。

## 读取已有结果

在结果区填写已有 `analysis_manifest.json` 的完整路径。可以直接用公开包的 `comparison/analysis_manifest.json`，只读取记录并调用 `analyze_results`。

结果展示逐种子的原始估计、对数值、请求/提交/返回、正式分母、状态、错误、告警与误差。方法表由现有分析器按目标、策略和预算档位汇总。参考缺失或不匹配时误差留空。四份 CSV 可以下载，完整 `analysis.json` 与输出保存在任务目录。

`budget_stopped` 可以表示预算用完时有估计。低权重告警是当次样本的诊断，请结合估计可用性、同工况独立参考和来源记录读表。当前没有通用排名资格。

## 验证范围

公开 CPU 回归检查工艺角冲突和传递、本地 HTTP 校验、并发限制、失败后保留分析与超时终止。运行分支使用替代进程测试。浏览器实测校验、冲突拒绝、表单更新和公开包的离线结果，覆盖桌面与手机宽度。本轮新增网页入口未执行真实电路仿真。
