## 预检没有跑什么

只允许求解器执行 `Xyce -v`，没有传网表。元数据构建阶段用保护钩子禁止子进程、execute_xyce 和目标采样。没有新电路测量、没有采样，也未重跑 64 项泛化检查。

第一次预检停在 driver_sizes 比较。原因在独立预检脚本：两个内存 tuple 字段与参考 JSON 的 list 不相等。DriverSizes.to_dict 使用 dataclass.asdict 保留 tuple，而保存 JSON 会变成 list。只在脚本中按相同 JSON 表示比较；字段、数值和生产代码未改。首次失败目录和输出保留，成功结果另存，不是忽略实际驱动差异。具体转换见 [transport_types.json](launch_preflight/transport_types.json)。最终成功预检查询版本一次，首次失败预检也查询过一次，本轮总计两次版本查询。

下载时一次网络 EOF、一次旧 gh 不支持 --output，均保留在日志；最终用本机支持的 --dir 下载同一个清单。另一次读取命令忘记激活 openyield 导致 numpy 缺失，改为使用已有环境后成功，没有安装依赖或调整算法。
