# ACS 初始化对照结果

这次完成了初始化坐标说明、规则冻结和双失效区域解析对照。**本例中球面组误差更小，但没有将它作为修复接入生产算法。** 历史电路严重低估的原因仍未查清。

## 为什么做

上一项工作说明，在候选点、核参数和混合系数满足指定条件时，分簇混合可以化成扁平混合。因此没有依据把“没调用聚类”直接当作历史低估的原因。本项转而检查一处明确的行为差异。生产 `ACS._initial_sampling` 在参数盒内均匀抽样；作者材料描述逐层扩大的球面预采样。

本次不恢复聚类，不改分量系数，不改正式估计公式，只在一组运行中替换初始化。测量由可计算的数学函数给出，后续继续走真实 ACS 生产循环。

## 球面在哪个空间

本次球面定义在没有物理单位的 `z` 空间，目标分布为两个独立标准正态。每一维以 0 为中心、标准差为 1，半径是 `sqrt(sum(z**2))`。不能直接把伏特和迁移率等原始参数数值拼成同一尺度的球面。

对当前物理工艺，普通参数可用 `x=mu+sigma*z`，其中 `sigma=abs(mu)*relative_std`。但迁移率要求正值，直接这样换算可能产生负数。研究脚本提供了一个**尚未接入生产入口**的分位数映射，先算 `z` 在标准正态里的百分位，再取正迁移率分布的相同百分位。公式和实现限制见 [预案](PROTOCOL.md#坐标和正迁移率)。

映射得到的一般是物理空间的曲面，不是物理球面。截断明显时，`z=0` 对应条件中位数，未必等于原名义值。公开检查覆盖了相对标准差 5%、50%、200% 的固定点，独立核对了截断分布的尾概率和生产目标密度。数值计算若失去正值支持域就报错，不剪裁、不悄悄重抽。这不代表任意极端输入都已经验证。

这是适配当前独立工艺的一种研究选择。所查作者材料没有给出本项目工艺的这份变换，不能据此宣布忠实复现了作者的全部坐标定义。相关工艺或其他分布也未支持。正式 ACS 的物理高斯提议如何满足正迁移率约束，仍需另行处理。

## 两组怎样比较

共同目标为二维标准正态，失效发生在 `z[0]<-2` 或 `z[0]>2`。左右两块区域互不相连。真值来自正态尾积分：

\[
P_{fail}=\operatorname{erfc}(2/\sqrt{2})=0.04550026389635844.
\]

也就是约 4.5500%，不是小样本 MC 参考。64 个种子在实验前固定为 2026111800–2026111863，每个种子两组都运行。

盒式组直接调用生产初始化，使用本例合成盒 `[-4,4]^2`。球面组按冻结层次采样。两组都只保留前四个失效点，再花四次测量复测。正式阶段使用相同核协方差 `diag(0.5,0.5)`、每批 16 点、相同失效池更新，不混入目标抽样，不裁剪，不按 FOM 提前停止。

每次总预算都是 260 次测量。初始化和复测收费，且不计入正式估计分母。剩余放不下下一整批时，在生成前停止。研究中的初始化上限则在测量提交前检查，历史盒路径可能先生成下一批再被拒绝，生成数和测量数分别记录。完整批次中的额外候选保留在证据里，不增加中心数量。

## 实际结果

| 项目 | 历史盒式组 | 球面研究组 |
| --- | ---: | ---: |
| 计划运行 / 有估计 | 64 / 64 | 64 / 64 |
| 无估计比例 | 0% | 0% |
| 初始化测量曾覆盖两侧 | 63/64 | 63/64 |
| 入选四点覆盖两侧 | 55/64 | 56/64 |
| 正式样本覆盖两侧 | 35/64 | 56/64 |
| 平均失效率估计 | 0.0269636829 | 0.0386598470 |
| 跨种子标准差 | 0.0104317017 | 0.0108671494 |
| RMSE | 0.0212302830 | 0.0127687511 |
| MAE | 0.0202048395 | 0.0101171136 |
| 估计大于 1 的次数 | 0 | 0 |
| 生产权重诊断告警次数 | 0 | 0 |
| 每次初始化测量 | 16 | 48 |
| 每次复测 | 4 | 4 |
| 每次正式估计测量 | 240 | 208 |
| 每次总提交 / 返回 | 260 / 260 | 260 / 260 |

表里的概率使用 0–1 单位。RMSE 是每次估计减真值，平方后平均再开方；MAE 是差值绝对值的平均。它们在这里衡量这批运行的误差。一般只对有估计的运行计算，因此始终同时列出成功数和无估计比例。

两组共提交、返回 33,280 条解析测量，其中正式估计 28,672 条，初始化 4,096 条，复测 512 条。真实电路仿真为 0。各组全部保留，没有挑选成功种子或去掉差结果。

**这项结果最重要的区别是“测到”不等于“留下并继续用到”。** 两组初始化覆盖两侧的次数相同，入选四点的覆盖也接近，但正式采样覆盖不同。起点的具体位置和后续分布也会受初始化影响，不能把误差差异全部解释为是否发现第二个失效区域。本次没有把这些因素进一步拆开研究。

球面组花了更多初始化成本，正式样本更少；本例误差仍较小。这是本例观察，不构成一般优势。两组平均值都低于真值，有限种子的平均偏低不能单独证明整个估计器有偏。没有低权重告警也不能保证结果准确。

## 是否真的复用了生产路径

生产文件没有改动。研究脚本调用这些已有路径：

1. `ACS.start_estimate` 初始化、复测和循环，球面组只替换 `_initial_sampling`。
2. `_calculate_weight`、`_construct_mixture_norm` 生成每批真实提议。
3. `mixture_gaussian.sample/log_pdf` 生成正式样本、计算本批密度。
4. `_estimate_batch` 记录本批样本、密度、测量与失效标记，然后 ACS 更新失效池。
5. `weight_summary` 用已完成正式记录汇总结果。

共 1,792 个正式批次。保存每批实际中心、方差和系数，再用独立 SciPy 高斯公式重算密度。最大对数密度差为 `1.7763568394002505e-15`。独立重算正式贡献的均值，与生产统计结果一致。初始化和复测未进入分母；旧中心可以继续使用，旧贡献没有重复累计。

另读了生产抽样器 `gmm_v2.py:245–268`。它先按混合系数抽各分量数量，再按各分量高斯生成，返回时按分量分组。当前 ACS 整批测量后才更新，没有在分组顺序中逐点改分布。数值核对和这项代码检查仍不是整个自适应算法的一般无偏性证明，也没有证明其 FOM 置信解释。

新增 4 项公开检查覆盖球面半径、正迁移率映射、预算刚好用完与整批放不下，以及候选不足时无估计。主实验没有候选不足；该行为由单独固定反例测试，不是更换主实验门限凑出来的。

## 结论与边界

本次回答了球面坐标、截断映射、有限初始化规则和本例误差比较。**证据足以保留这项研究选择，不足以直接替换生产初始化。** 作者原始半径程序、完整 ACS 逐轮更新与论文的对应、高维工艺约束及历史 SRAM 低估仍未验证。

这里收口，不追加种子、门限或电路实验。若下一项要判断历史电路结果是否受初始化影响，应另定资源方案，冻结同一物理目标与总成本，再比较起点覆盖及估计结果；不能将本例 4.5500% 的真值借给其他工况使用。
