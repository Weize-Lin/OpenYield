# ACS 初始化解析对照预案

本预案在查看本次种子结果前冻结。只研究初始化对后续同一套 ACS 代码的影响。没有电路，没有 Xyce，也没有改动正式算法。配置见 [protocol.json](protocol.json)。

## 论文给了什么

第一作者博士论文第 3.2.1 节和 ISPD 作者报告提出在球面上预采样、逐步增加半径来取得多个失效起点。博士论文给出的实验设置包括每层 100 点以及 10% 失效这一标准。所查材料没有提供足够细节来确定完整半径序列、随机方向生成程序、超出候选数量的保留顺序或有限总预算下的停止办法。这里不会将补充的实现选择称为论文原版。

[博士论文，印刷页 31–33](https://escholarship.org/content/qt58f61961/qt58f61961_noSplash_5af6b5baafcfcae77097c91fc3fa01ea.pdf#page=45) · [ISPD 作者报告，第 11 页](https://ispd.cc/slides/2019/25_PD_Adaptive.pdf#page=11)

## 坐标和正迁移率

不同参数有不同单位，不能把伏特和迁移率的原始数值直接当成等尺度距离。对本次解析问题，先定义无量纲坐标 `z`，目标是二维独立标准正态，即每一维中心为 0、标准差为 1。球面指 `sum(z_i**2) = r**2`，与物理参数空间中的球面不是一回事。

当前平台 `IndependentProcess` 的普通参数可用 `x = mu + sigma*z` 映射。`sigma = abs(mu)*relative_std`。迁移率 `u0` 另有 `u0 > 0` 的条件。简单仿射变换在足够大的半径下可能产生负迁移率；直接剪成小正数会改变抽样规则。

本研究脚本另给出一个候选映射。记标准正态累积分布为 `Phi`，迁移率截断前的中心和尺度为 `mu, sigma`。

\[
a=-\mu/\sigma,\qquad
x=\mu+\sigma\Phi^{-1}\{\Phi(a)+[1-\Phi(a)]\Phi(z)\}.
\]

这句话的操作含义是，先看 `z` 在标准正态里排在什么百分位，再取正迁移率分布的相同百分位。程序用等价的对数尾概率计算，减少数值舍入。如果仍丢失支持域，明确报错，不剪裁、不悄悄重抽。

这能将完整标准正态分布映射到当前独立截断工艺，但球面本身只是用于找起点，不是目标工艺抽样。映射后的曲面一般不是物理球面。`z=0` 对应截断分布的中位数，截断明显时不等于截断前名义值。这是本项目提出并检查的映射选择，尚未接到生产初始化，不能声称论文规定了它。它也不支持任意相关矩阵或其他工艺分布。

物理目标密度仍由 `IndependentProcess.log_pdf` 定义。正式 ACS 当前在物理坐标构造高斯核；若将整个正式估计搬到 `z` 坐标，需要同时转换测量函数和密度，不能只换样本而沿用旧权重。正迁移率支持域对正式提议仍是独立问题，本次解析对照没有解决它。

## 只改变什么

| 项目 | 历史盒式组 | 球面研究组 |
| --- | --- | --- |
| 初始化样本 | 调用现有 `ACS._initial_sampling`，二维盒 `[-4,4]^2` | 半径依次为 1、2、3、4，每层 16 点 |
| 方向 | 现有独立均匀抽样 | 独立标准正态向量除以长度，得到均匀球面方向 |
| 成功条件 | 已完成批次中累计取得 4 个失效点 | 相同 |
| 保留规则 | 前 4 个，保持生产行为 | 相同，不按区域补点或重排 |
| 初始化上限 | 64 次解析测量 | 相同 |
| 复测 | 入选的 4 点再测一次，计入总预算 | 相同 |

半径序列、16 点、4 个起点、64 次初始化上限和前四保留，都是本次项目选择。盒宽也是本例的合成配置，不是历史 SRAM 边界文件。完整批次中其余测过的点保存在证据中，不额外作为中心。若候选不够，无估计单独报告。历史盒路径在下一批已生成后、送测前才检查初始化上限，因此可能有生成但未测量的样本；分开记录生成、提交和返回，不收取未测量批次的测量成本。

## 固定目标和成本

失效事件是 `z[0] < -2` 或 `z[0] > 2`。这两个区域互不相连。真值直接由正态尾积分得到 `erfc(2/sqrt(2))`，约为 0.0455003。这里没有用小样本 MC 充当真值。

预登记种子为 2026111800 至 2026111863，共 64 个；每个种子两组都执行。每组总测量上限 260，包含初始化、复测、正式估计。正式每批 16 点，核协方差固定为 `diag(0.5,0.5)`，不混入目标抽样，不裁剪，不更改生产代码的候选更新。两组各自从同一种子重设 NumPy 和 PyTorch；分布不同，不承诺相同输入点。

使用生产 `ACS.start_estimate(strict_budget=True)`，由它决定每批提议、生成样本和更新失效池。正式分母只包含完成的正式批次。已有中心可用于下一轮分布，旧样本贡献不能再算一遍。不使用观察估计值的 FOM 提前停止；下一整批放不下时在生成前停止。固定总预算下，初始化花费不同会导致正式样本数不同，这是本项研究要报告的成本，不人为补齐。

## 必须保留的结果

逐种子报告初始化测量、入选起点和正式采样各自覆盖了几个失效区域；同时报告无估计比例、原始估计、超过 1 的估计、告警和分阶段成本。只对有估计的运行计算条件 RMSE、MAE 和跨种子标准差，旁边必须列出成功数和无估计比例，不填零补失败。

每批保存生产提议中心、核方差和分量系数，用独立 SciPy 公式重算当批密度，再核对生产记录与正式分母。保留完整轨迹到忽略目录，公开精简的逐运行表和汇总。测试会禁止实验期间启动子进程。

这是一项有上限的二维机制研究。即使出现较小误差，也不能推广为高维 SRAM 有效、论文复现完成或整个自适应估计器的一般无偏性。固定候选不足的停止会形成条件成功子集；本报告明确展示这个选择机制，不用成功子集误差冒充全体性能。
