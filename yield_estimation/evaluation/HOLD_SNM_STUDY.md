# 单单元 6T 保持裕量对照实验

保持裕量（hold SNM）表示单元保住已存数据时能承受多大的电压扰动。本用例把裕量低于 327.65 mV 的样本判为失效。

## 从仓库根目录运行

在 Linux 或 WSL 上用根目录的 `environment.yml` 建环境，清单已包含 CPU 版 PyTorch 和 HSCS 聚类用的 scikit-learn 1.6.1。
验证使用 Python 3.9.19、NumPy 1.26.4、SciPy 1.13.1、PyTorch 2.8.0+cpu 和 Xyce 7.4 开发版（`gb7bb12d8`）。

```bash
conda env create --file environment.yml
conda activate openyield
Xyce -v
python -m unittest discover -s tests -p test_evaluation_weight_contract.py -v
```

预览只列计划命令。加 `--run-xyce` 正式跑，输出目录必须是新目录。

```bash
python -m yield_estimation.evaluation.hold_snm_study --output-dir outputs/hold_snm_study --jobs 4
python -m yield_estimation.evaluation.hold_snm_study --output-dir outputs/hold_snm_study --jobs 4 --run-xyce
```

如果只想先看一次 Xyce 输出，可以用随仓库提供的 [少样本 MC 示例](cases/hold_snm_6t_configurable.json)。它采用自己的示例门限。

```bash
python -m yield_estimation.evaluation.run_diagnostics \
  --config yield_estimation/evaluation/cases/hold_snm_6t_configurable.json \
  --algorithms mc --output-dir outputs/hold_snm_first --run-xyce
```

## 实验条件

- 电路为 1×1 6T，TT 工艺角，1 V，27 °C。每条样本有六只管子的 `vth0`、`u0`、`voff`，共 18 个量。独立工艺波动的标准差是名义值绝对值的 5%，迁移率限定为正。完整输入见 [固定配置](cases/hold_snm_6t_study.json)。
- 用种子 8201 的 128 条先导样本选保持裕量的 15% 分位并取到 0.01 mV。取到 327.65 mV 时，20 条低于门限，先导样本仅用于选门限。
- 正式参考用种子 8311–8314，各跑 256 条独立 MC。算法比较用种子 9101–9108，每个算法每次给 48 条仿真预算。相同种子编号可以重复运行，算法的抽样规则各不相同。
- 四种重要性抽样算法从名义参数两侧各三个标准差的范围内开始找初始失效，初始批次 4 条，需要找到 1 条失效。估算阶段每批 1 条。MNIS 显式选择 `target_diagonal` 协方差，HSCS 显式选择 `nominal` 搜索起点，AIS、ACS、HSCS 的配置方差为 `1e-5`。这是本次参数设置。
- 初始搜索和复测都计入预算。报告保存请求名额、实际提交和返回数。失效概率没有结果、工况不同或实际仿真不足 48 条，会在该种子留下原因，算法汇总误差留空。

## 实测记录

在 WSL 的独立新环境中，用 Git 导出的源码复跑了完整实验。Conda 从本机包缓存安装，pip 按环境清单安装依赖。参考值、40 轮估计、仿真成本及告警都与原记录核对过。

失效定义为保持裕量低于 327.65 mV。
独立 MC 参考为 142/1024（13.867%），95% Wilson 区间 11.885%–16.119%。

每个算法跑 8 个种子，每次预算 48 条，包含找失效点和复测。
工况和预算通过表示本轮有估计、提交与返回齐全且工况一致。低权重告警单独记入，保留这些轮次的误差。
低权重告警的分母是有权重诊断的种子数。任何种子未通过工况与预算核对时，汇总误差留空。
误差以参考点估计为准，参考值本身也有抽样误差。结果适用于本次工况和报告所列算法设置。

## 这组低估怎么排查的

用前三种单变量算例分别检查等分布、平移正态和混合正态的权重，并检查零目标密度的抽样也留在分母。
随后用已有的电路样本和测量账本复放四种算法，按每次实际抽样的提议分布参数独立重算密度。
复放覆盖 32 轮、1,336 条估算样本，重新生成的样本逐项一致。重算失效率和已记录结果的最大相对差为约 `5.1e-6`。

用各参数的目标标准差换算距离。独立 MC 的 142 个失效样本到工艺中心的距离中位数为 4.37。
各轮估算样本距离的中位数范围为 MNIS 7.62–9.97、AIS 9.32–12.42、ACS 8.32–9.88、HSCS 5.20–8.69。
例如 ACS 有 320/344 条估算样本判为失效，它们的权重普遍很低。这个工况下，
原有提议在 48 条预算内集中在目标工艺密度偏低的区域，证据指向覆盖不足。
这些检查覆盖这里的配置和实现路径。后续改变提议分布需要另记实现与对照协议。

[逐轮权重复核数据](../../docs/data/HOLD_SNM_WEIGHT_AUDIT.csv)。CSV 中 `requests` 是仿真批次数，每轮实际仿真条数均为 48。

## 固定预算下的 MNIS 混合提议对照

为检查原提议覆盖不足是否能缓解，在同一个工况上预先固定种子 9301–9308，保持门限和 48 条预算。
两个 MNIS 从相同的初始和复测样本出发。新方案只改估算阶段。
记原工艺概率密度为 f，基础 MNIS 提议为 g，混合提议 q = 0.5 f + 0.5 g。
按 q 抽样时用 f/q 折算，因此每条样本的权重至多为 2。
这个界限限制了最大权重，估计误差仍需实际比较。

复跑可复制 [固定配置](cases/hold_snm_6t_study.json)，依次将 `seed` 设为 9301–9308。
直接 MC 用原入口。配置化 MNIS 用 `mnis_target_fraction: 0`，混合方案设为 `0.5`。
两个 MNIS 均用 `mnis_run`，参数为
`--initial-batch 4 --initial-failures 1 --estimation-batch 1`。每次用独立输出目录。

三个方案各 8 个新种子，每次返回 48 条。门限 327.65 mV，沿用独立 MC 参考 142/1024（13.867%）。
两个 MNIS 的初始化与复测样本逐项相同。估算阶段的混合提议给原工艺分布 50% 概率。

| 方案 | 平均估计 (%) | RMSE (百分点) | 低权重告警 | 权重 ESS 中位数 |
| --- | ---: | ---: | ---: | ---: |
| 直接 MC | 15.365 | 5.512 | — | — |
| 配置化 MNIS | 0.00011532 | 13.87 | 8/8 | 1.17 |
| MNIS + 50% 原工艺混合 | 15.116 | 6.991 | 0/8 | 21.00 |

混合方案实际从原工艺分布抽了 170/344 条估算样本。最大观测权重为 2。

结果限于这一个工况、这个预算与已记录的方案。
